# HR-Payroll-SQL-Project
SQL-based HR and Payroll Management System demonstrating relational database queries and data analysis.


## Project Overview

The **HR & Payroll Management System** is a SQL-based database project designed to manage employee information, department details, salary records, attendance, and project allocations.

This project focuses on practising SQL queries and database operations, from basic data retrieval to advanced querying techniques.

## Database Structure

The project uses a database named `hr_payroll` with six tables:

- **employees** – Employee information and department details
- **departments** – Department information
- **salaries** – Basic salary, bonus, and deductions
- **attendance** – Employee attendance records
- **projects** – Project information
- **employee_projects** – Employee and project allocation details

## SQL Concepts Covered

### 1. Basic Queries
- SELECT statements
- WHERE conditions
- Filtering and sorting
- ORDER BY

### 2. Aggregate Functions
- COUNT()
- AVG()
- MAX()
- SUM()

### 3. Grouping and Filtering
- GROUP BY
- HAVING

### 4. Joins
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN alternative using UNION

### 5. Subqueries and Nested Queries
- Employees earning above average salary
- Highest earning employee
- Second-highest salary
- Employees not assigned to projects
- Departments with average salary greater than Finance

### 6. Advanced SQL
- RANK() window function
- Views
- DML operations (INSERT, UPDATE, DELETE)
- Constraints
- Indexing

## Sample Business Queries

The project also includes queries to analyse:

- Total company payroll cost
- Employee working on the maximum number of projects
- Department with the highest employee count
- Least busy project
- Employees with 100% attendance
